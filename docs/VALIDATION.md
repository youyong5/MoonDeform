## 已验证

| 项目 | 结果与证据 |
| --- | --- |
| 格式与接口 | `moon fmt --check`；`moon info` 后保留生成接口 |
| 编译检查与构建 | `moon check --target all --deny-warn`；`moon build --target all --deny-warn` |
| 数值／API 测试 | 31 项独立测试，在 native、js、wasm-gc、wasm 四后端上均通过 |
| 上游一致性 | 固定上游 C++ 距离内核，40 组非退化输入、160 个坐标值；MoonBit 误差阈值 1e-9 |
| 解析与数值依据 | 质量加权质心、柔度单步解析解、子步内乘子累积、面积与角度有限差分梯度 |
| 失败边界 | 退化几何、无效句柄、NaN／梯度溢出、帧失败保留外力、构造失败回滚、自定义回调重入保护 |
| 动态场景 | 软体 360 帧落地、面积误差低于 2%；相同输入重复轨迹相等 |
| 独立消费模块 | workspace 中单独模块，native 与 js 实际编译运行公开 API 与自定义约束 |
| 浏览器桥接 | 编译真实浏览器 JS 模块，Node 下运行三场景各 360 步，检查有限数值、地面半径、拖动桥接及错误恢复 |
| 无界面示例 | native 实际运行，16 粒子、33 约束、240 帧；面积从 1.1021282852 到约 1.1020052140 |

测试项数量不等于所有物理现象正确；40 个距离参考配置位于一项测试内，不计作 40 项不同测试。

## 单次 JS 运行耗时

使用 `scripts/bridge_check.cjs`，Node v24.22.3，4 个子步、每子步 8 次迭代，360 个固定步长帧。一次记录：

| 场景 | 粒子数 | 360 帧总耗时 |
| --- | ---: | ---: |
| 绳索 | 25 | 136.41 ms |
| 弹性网格 | 99 | 942.59 ms |
| 弹性环 | 24 | 115.88 ms |

包含编译模块中的求解／诊断调用，不包含 Canvas 绘制。它是本机一次 smoke workload，不是跨机器性能承诺，也不用于证明大规模性能。
