## 单次 JS 运行耗时

使用 `scripts/bridge_check.cjs`，Node v24.22.3，4 个子步、每子步 8 次迭代，360 个固定步长帧。一次记录：

| 场景 | 粒子数 | 360 帧总耗时 |
| --- | ---: | ---: |
| 绳索 | 25 | 136.41 ms |
| 弹性网格 | 99 | 942.59 ms |
| 弹性环 | 24 | 115.88 ms |

包含编译模块中的求解／诊断调用，不包含 Canvas 绘制。它是本机一次 smoke workload，不是跨机器性能承诺，也不用于证明大规模性能。

2026-11-24 新增四项独立物理依据的回归测试，本地四后端各 41 项通过：自由落体对连续解析轨迹的子步收敛、非等质量粒子仅受内部约束时的线动量与质心轨迹、切向衰减和法向恢复共同作用下的动能，以及残差／梯度缩放时柔度平方缩放的解析响应。它们不构成任意场景的能量守恒或稳定性承诺。
