# 范围、约束与生态贡献

## 项目定位

MoonDeform 是可嵌入的二维可变形物理基础库。浏览器 playground 是消费者之一，库本身不依赖该页面。宿主负责时间调度、输入、渲染与业务对象，求解器负责物理状态与约束。

核心模块无第三方运行时依赖，适合嵌入 MoonBit 游戏、交互动画、教学程序和批量模拟。`Body.edges` 只提供拓扑信息，不绑定绘图库或引擎对象。项目不声称这些外部项目已经采用该库。

## 算法与工程增量

XPBD 是成熟算法，本项目不把它称为算法创新。生态贡献集中于：

1. 将固定上游的核心求解能力移植为 MoonBit 可调用、无需 C++ FFI 的实现。
2. 以同一求解管线处理距离、二维有符号面积、弯曲及调用方自定义约束。
3. 将伸长柔度、面积柔度与弯曲柔度分开表达，支持不同形变效果。
4. 用公共 API 组合绳索、三角网格和封闭软体；业务应用可提交自有拓扑。
5. 在消费接口上提供数值错误回滚、只读快照及对外可解释的数值边界。

已有 MoonBit 刚体库也有绳索和弹簧关节，故绳索演示不是独立差异。重点是可变形网格的粒子自由度、面积约束和可扩展标量投影。生态检索是有日期的范围检查，不是“全球首个”的证明。

## 标量约束接口

调用方提交粒子句柄、残差 C 与按句柄排列的梯度。对于每个子步 h：

```
alpha = compliance / (h*h)
delta_lambda = -(C + alpha*lambda) / (sum(w_i*|gradient_i|^2) + alpha)
x_i += w_i*gradient_i*delta_lambda
```

lambda 在子步内迭代累积，子步之间重置。外力在整个调用帧内持续作用，成功后清空。固定点的逆质量为零。

自定义回调可表达滑轨、位置关系或新材料约束，且无需修改 World。此接口只支持标量等式约束；不把它描述为支持任意互补约束、任意碰撞模型或任意物理材料的完整插件系统。

## 帧推进

1. 校验时间步并保存当前帧状态。
2. 每个子步积分外力、重力与阻尼，预测位置。
3. 迭代求解材料约束，再投影静态接触。
4. 从修正后位置重建速度，处理接触恢复和切向衰减。
5. 检查有限数值、计算诊断、提交时间并清空外力。

失败通过 errdefer 回滚当前帧；构造器失败也回滚本次拓扑追加。约束与粒子句柄保持索引稳定。快照复制位置，避免宿主无意修改内部状态。

## 精度与范围

面积保持不等于防翻转，不保证局部单元始终正定。接触仅覆盖节点对静态平面和圆形，没有自碰撞、边接触或 CCD。含多个互相冲突的硬约束时，有限次顺序投影可能留下残差。用户需结合网格尺度、柔度、子步与迭代预算设置材料。

当前每次约束评估会分配少量临时数组，step 的错误回滚也保存快照。优先保证可解释的接口与正确性，后续性能工作应在明确规模基准上进行，不能承诺 GPU 级或百万粒子吞吐。

## 后续扩展

以实际应用和误差基准驱动：单元防翻转、节点／边自碰撞、空间加速结构、三维布料、批量或无分配求解。每项均应独立验证，不包含在 0.1.0 的完成声明中。
