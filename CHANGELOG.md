# Changelog

## 0.1.0 — 2026-11-24 (local development release)

- Port the distance projection from a pinned MIT-licensed PositionBasedDynamics commit.
- Add renderer-independent 2D particle integration and scalar XPBD constraints.
- Add signed-area, angle bending and consumer-defined constraints.
- Add rope, triangulated grid and closed elastic-ring constructors.
- Add static plane/circle contacts and recoverable numerical-error rollback.
- Add C++ reference fixtures, finite-difference gradient validation and independent API consumer.
- Add a static playground compiled from the same MoonBit library.

Not yet published to Mooncakes or a remote GitHub repository. Numerical, browser and platform limitations are recorded in docs/VALIDATION.md and README.md.
