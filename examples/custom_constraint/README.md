# 用公开回调实现圆形轨道

本示例让一个有质量的粒子在重力下沿半径 1.5 的圆周摆动，只使用 `World`、`Vec2` 与 `add_custom`。它展示宿主如何添加求解器尚未内置的几何等式约束，无需修改库内部或依赖渲染器。

在仓库根目录执行：

```sh
moon run examples/custom_constraint --target native
moon run examples/custom_constraint --target js
```

设 `d = position - center`，回调给出残差 `C = (dot(d,d)-radius²)/2` 和梯度 `d`。该残差的单位是长度平方；示例采用硬约束。若改为柔性约束，请依据 [API 量纲说明](../../docs/API.md) 设置柔度，不能直接套用距离残差的数值。

轨道约束让粒子留在圆周上；`add_circle` 则把粒子排斥在实心障碍外。两者的用途不同。

示例从圆周开始，在 480 帧中每帧推进 `1/120` 秒，并检查每帧径向误差不超过 `1e-7`。程序输出粒子数、约束数、模拟时间与最大径向误差，超出阈值时失败。圆心是梯度为零的奇点，不能用该残差从圆心初始化；这也说明自定义约束必须明确其退化域。

这个检查验证轨道几何精度，不声称摆动能量守恒；配置包含阻尼，位置投影本身也可能产生数值耗散。
