# 静态宿主接入示例

该页面使用同一个 MoonBit 求解库绘制弹性环、绳索和二维网格。Canvas、指针事件及墙钟时间由宿主处理；求解、材料更新和诊断通过公开库 API 完成。

## 构建与运行

```sh
python3 scripts/build_demo.py
python3 -m http.server 8765 --directory dist
```

打开 `http://localhost:8765`。构建还生成可直接打开的 `dist/MoonDeform-demo.html`，无需服务器或 CDN。

## 保留状态的材料调整

拉伸柔度滑块调用适配器的 `tune(value)`，进而使用 `constraint_info` 按实际约束类型调用 `set_constraint_compliance`。它不依赖构造器内部的句柄排列，也不重建世界。当前位置、速度、拓扑和模拟时间都保留，后续步进使用新材料。

本示例的材料策略是：距离柔度等于滑块值；网格面积柔度为其 0.1 倍，弹性环面积柔度为其 0.01 倍；弯曲柔度保持独立。这是三个预设场景的建模选择，不是不同量纲柔度之间的通用换算。自定义约束的材料也不会被这个滑块改写。

切换场景或点击“重置”才会重新建模、清零模拟时间。无效调参（负数、NaN、无穷大）在任何更新前被拒绝；有效调参可以清除适配器错误提示。

## 桥接与诊断

示例安装的 `globalThis.moonDeform` 包含 `reset`、`step`、`snapshot`、`drag`、`tune`、`error`。这是示例宿主适配器，不是核心库要求的全局接口。

`snapshot()` 除位置、边、时间、动能及旧的混合最大残差外，还提供：

- `stretch_error`：启用距离约束的最大绝对残差，单位为场景长度单位。
- `material.distance`、`material.area`、`material.bend`：当前预设场景各类约束的柔度；不存在的类型为 `null`。各预设中同类型柔度一致，不代表任意世界只能使用统一材料。

页面展示距离残差，不将长度、面积、角度混合成一个精度分数。残差反映约束偏离，不保证形状不会自交或翻转。

## 验证

`scripts/bridge_check.cjs` 在 Node 中调用真实编译模块，覆盖三个场景、360 帧、运行时调参前后的状态连续性、不同类型的材料策略及无效更新的原子性。

`scripts/browser_check.cjs` 在 Chromium 的桌面静态站与移动视口单文件页面上操作真实控件：暂停、单步、拖动、调整柔度，确认时间／位置／拓扑未被调参重置、后续步进继续，以及显式重置仍然有效。它由 CI 单独运行，不将 Node 检查当成浏览器验证。
