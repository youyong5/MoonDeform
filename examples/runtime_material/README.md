# 在同一个世界中调整材料

该示例使用公开的 `set_constraint_compliance` 与 `constraint_residual`，在不重建拓扑的情况下将受载弹簧由柔软切换为更柔软，最后切换为硬约束。它适合用作游戏、动画编辑器、参数优化工具的无界面接入样例。

在仓库根目录运行：

```sh
moon run examples/runtime_material --target native
moon run examples/runtime_material --target js
```

固定端连接质量为 2 的粒子，重力大小为 10，初始静止长度为 1。柔度从 0.001 改为 0.002 时，理论平衡伸长量 `mass * gravity * compliance` 分别为 0.02 与 0.04。每阶段推进 1600 帧，随后通过有符号距离残差检查伸长量，允许误差为 `1e-4`。

最后将柔度设为 0，推进一帧并检查长度残差低于 `1e-7`。整个过程保持两粒子、一个约束及原有句柄，任何数值检查失败都会使示例失败。

这里的最大推进帧数、时间步与阈值是这个受载弹簧的验证设置，不是任意材料的收敛保证。残差单位取决于约束定义；其他约束的柔度应按 [量纲说明](../../docs/API.md) 设置。材料更新必须发生在帧间，不能从约束回调内部发起。
